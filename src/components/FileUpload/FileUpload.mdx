A drop zone for choosing files, and a card for each file with its progress and status. People click anywhere in the zone, or drop files on it.
The product does the upload itself and tells the component how far each file has got.

<Canvas of={FileUploadStories.Playground} />
<Controls of={FileUploadStories.Playground} include={['hint', 'accept', 'maxFileSize', 'multiple', 'disabled']} />

```tsx
<FileUpload
  hint="JPEG, JPG, PNG, SVG formats, up to 5 MB."
  accept="image/png,image/jpeg,.svg"
  maxFileSize={5 * 1024 * 1024}
  files={files}              // [{ id, name, size, status: 'uploading' | 'completed' | 'failed', progress }]
  onSelect={startUploading}
  onCancel={cancel} onRemove={remove} onRetry={retry}
/>
```

### Several files

<Canvas of={FileUploadStories.SeveralFiles} />

### A file too big

<Canvas of={FileUploadStories.AFileTooBig} />

A file that doesn't pass the check (too big, or a type not in `accept`) isn't added and gets no card: the zone turns red and the reason is under it, in the Hint text of the fields (*team-photo.png is larger than 5 MB.*). The next file chosen clears it. The product shows its own error the same way, with `error`.

### Try again

<Canvas of={FileUploadStories.TryAgain} />

When the upload itself fails (the network, the server), the card offers *Try again*. The product sends the file once more.

### Use the keyboard

<Canvas of={FileUploadStories.UseTheKeyboard} />

The whole zone is one button: Tab reaches it, Enter or Space opens the file dialog. Tab then reaches each card's action (*Cancel uploading…*, *Remove…*, *Try again…*).

### Upload a logo

<Canvas of={FileUploadStories.UploadALogo} />

### Crop a logo

<Canvas of={FileUploadStories.CropALogo} />

The Figma *Upload photo flow*. The avatar's container is the button (its edit badge stays a picture): without a logo it opens *Upload logo*; the chosen picture goes on to the crop in the same modal, and the back arrow returns to the upload. Drag the picture into the round window, zoom with the slider, its − and +, or the + and − keys; the picture always covers the window. *Save* puts the result in the avatar. With a logo, the avatar opens a menu: *Edit logo* crops the original again from where it was left, *Remove* takes the logo away.

`ImageCrop` is the window and the zoom; `cropImage(src, crop)` gives the square result (512 × 512 PNG) for the product to upload. Keep the original picture and the crop to edit it later.

```tsx
<ImageCrop src={original} label="Logo position" value={crop} onChange={setCrop} />
const logo = await cropImage(original, crop);
```

## Design decisions

What the code adds to the Figma file, and why:

- **The product uploads, the component shows.** PrimeReact can send files itself, but with one progress for all of them and no status per file. Here PrimeReact gives the file dialog, the dropping and the size check; the product sends the files and passes each one's status and progress back. Every product has its own server and rules, so this keeps the component usable everywhere.
- **The whole zone is a button.** In PrimeReact only a separate Choose button opens the dialog and the drop area can't be reached with the keyboard. Here the zone itself is the button, for the mouse, the keyboard and dropping.
- **Two kinds of failure.** A file that didn't pass the check never becomes a card: the zone turns red with the reason under it, as a field shows its error. A failed upload keeps its card, with *Try again*.
- **PrimeReact's message is never shown.** PrimeReact checks the size itself and puts a grey message above the zone; here the size is checked by the component, and only its red error shows.
- **File format icons.** The Figma *File format icon* set: fifteen formats in their colours, with a dark-theme sheet. Formats the set doesn't have (jpg, png, svg…) get the same sheet with a neutral label and their extension.
- **Sizes in the locale's numbers.** *1.2 MB* in English, *1,2 MB* in Ukrainian.
- **Focus you can see.** The zone shows the system blue ring with the keyboard.
- **Crop of our own.** PrimeReact has no crop component. The window is drawn here; the zoom is [Slider](?path=/docs/components-slider--docs) with `steppers` (PrimeReact Slider), from 100% (the picture fills the window) to 300% in steps of 10%. The picture can't move so far that an edge shows in the square.
- **The veil around the circle** is the overlay of Modal and Drawer (`--overlay`), not Figma's white at 20% with a blur: the system darkens things one way (see [Contributing/Tokens](?path=/docs/contributing-tokens--docs)).
- **Edit from the original.** Edit logo opens the original picture with the last zoom and position, so the logo can be zoomed out again, not cropped twice.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves to the drop zone, then to each card's action |
| Enter or Space (zone) | Opens the file dialog |
| Enter or Space (action) | Cancels, removes or tries again |
| Arrow keys (crop window) | Move the picture by 2% of the window; with Shift by 10% |
| + and − (crop window) | Zoom in and out by one step |

- The zone is named by its text: the call to action and the hint (formats and size).
- Each progress bar is named *Uploading my_cv.pdf* and reports its value.
- Finished and failed files are announced; the format icon is decorative, the file name says what it is.
- The crop window is named (*Logo position*) and says how to use it: *Drag or use the arrow keys to move it, + and − to zoom*. The zoom slider is named *Zoom*.
