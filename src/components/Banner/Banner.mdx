A full-width message for a page-wide or service-wide notice, with an optional description, action and dismissal.

```tsx
<Banner status="info" filled title="Scheduled maintenance" actionLabel="View details" actionHref="/status" />
```

## When to use

## Examples

Every example is a live story. Its steps also run as a test in the **Interactions** tab.

### Planned maintenance

<Canvas of={BannerStories.PlannedMaintenance} />

A notice for the whole service, with one link to the details. `actionHref` makes the action a real Link. Announced politely.

### Connection lost

<Canvas of={BannerStories.ConnectionLost} />

An error that needs fixing: announced at once (`role="alert"`), with Retry as a local action and no Close, so it stays until the problem is solved. An action doesn't dismiss the banner.

### Dismiss a notice

<Canvas of={BannerStories.DismissANotice} />

Close hides the banner and calls `onClose`. Keep essential information available elsewhere after dismissal.

### Long content

<Canvas of={BannerStories.LongContent} />

When the message doesn't fit one line, the banner switches to the long-text layout by itself, whatever `align` says: left-aligned, the icon on the first line, title and description in one paragraph, the action on its own row at the trailing edge and Close at the top. Centred text over several lines is hard to read, because every line starts in a new place. With room for one line again, the banner goes back.

## Design decisions

What the code adds to the Figma file, and why:

- **One size that fills its parent.** The Figma component is 1440px wide and 44px high; in code it takes its container's width and grows with wrapping text. Padding 12 × 48px, 8px between parts.
- **Not the banner landmark.** The ARIA `banner` role belongs to a site header, so the component doesn't use it.
- **Announced by urgency.** Error defaults to `role="alert"`; the rest to `role="status"`. A hidden `statusLabel` says the status in words.
- **No timer, no focus grab.** The banner doesn't disappear by itself or take focus when it appears. The page owns placement, stacking and focus after dismissal.
- **Long text chooses its layout.** The banner measures whether the whole message fits one line at its current width and switches to the long-text layout when it doesn't, so the rule holds on any screen without the product predicting widths.
- **Ghost is a solid surface.** Ghost uses `bg-base-0`, not a transparent fill, as in Figma.

## Statuses and alignment

<Canvas of={BannerStories.Statuses} />

**Filled** uses the status's muted background; **Ghost** uses the base surface, with the status carried by the icon and the text.
Figma defines no hover, pressed or disabled state for the whole banner; its action and Close have their own.

<Canvas of={BannerStories.Alignment} />

**Center** aligns the content with the whole strip, regardless of Close. **Left** aligns it with the 48px inset. **Long text** is always left-aligned, in either case.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves to the action, then Close; the blue ring shows |
| Enter | Follows the link or runs the action; closes the banner on Close |
| Space | Runs a local action or Close |

- Close is named *Close banner* by default; its 20px icon has a 24px target.
- When a focused banner is removed, the page should move focus to a nearby control.
