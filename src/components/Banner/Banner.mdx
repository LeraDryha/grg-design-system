A full-width message for a page-wide or service-wide notice, with an optional description, action and dismissal.

## Anatomy

<Canvas of={BannerStories.Anatomy} />

1. **Container:** a full-width strip, with a base or muted background; no border, corner rounding or shadow.
2. **Status icon:** a Base icon for the status: warning, error, success, information or neutral diamond.
3. **Title:** Body-md/Medium, 14/20, in `text-strong-1000`.
4. **Description (optional):** Body-md/Regular, 14/20, in `text-subtle-700`.
5. **Action (optional):** the Black, sm-20 Link appearance, using 14/20 Semibold. A link navigates; a button performs a local action.
6. **Close (optional):** the Grey, sm-20 Action Button with the *remove* icon, centred vertically and 12px from the trailing edge.

On narrow screens, scroll the anatomy card horizontally to see all six parts.

## Types

<Canvas of={BannerStories.Types} />

From the top:

- **Filled:** a muted background corresponding to the status.
- **Ghost:** `bg-base-0`, with the status conveyed by its icon and message. This is a solid base surface, rather than a transparent fill.

## Size

<Canvas of={BannerStories.Widths} />

Banner has **one size**. The Figma component is 1440px wide and **44px high** with single-line content. In code it fills its parent, including smaller page widths.

- Padding: **12px vertically**, **48px horizontally**.
- Gaps between the icon, title, description and action: **8px**.
- Status and Close icon frames: **20px**. Figma's Success icon is flattened to its 16⅔px drawing bounds; code preserves those bounds using the same Base icon.
- Text wraps when space runs out; the height grows and the Close button keeps its separate space.

## Alignment

<Canvas of={BannerStories.Alignment} />

From the top: **center** (the default) and **left**, as shown in the guidelines. Centre aligns the content group with the full container, independently of Close. Left aligns it with the 48px starting inset. Text and wrapped rows follow the chosen alignment.

## Actions and dismissal

### Navigation

<Canvas of={BannerStories.NavigationAction} />

Supply `actionHref` for navigation. The action is a real Link with native browser and Enter-key behaviour.

### Local action

<Canvas of={BannerStories.LocalAction} />

Without `actionHref`, the action is a PrimeReact button. Enter or Space calls `onAction`; this example counts retry requests. Actions do not dismiss the Banner automatically.

### Dismissal

Close is a button, reached with Tab and activated with Enter or Space. With `open` unset, Banner hides itself. With controlled `open`, `onClose` asks the parent to update visibility. Set `closable={false}` for a notice that must stay visible.

Banner has no auto-dismiss timer and does not take focus when it appears. The surrounding page owns placement, stacking, sticky behaviour and focus after dismissal.

## Long content

<Canvas of={BannerStories.LongContent} />

The icon stays with the title. Description and action can move to another row; long words wrap within the available width. The Close control remains at the trailing edge without overlapping the message.

## Accessibility

- Messages use `role="status"` and polite announcements by default; Error defaults to `role="alert"` and assertive announcements. Override `role` according to urgency, independently of colour.
- The message is atomic, so updates are announced together. A hidden, localisable `statusLabel` supplies the status in words; icons are decorative.
- This component does not use the ARIA `banner` landmark, which belongs to a site's header.
- Tab reaches the action and then Close. Enter activates either; Space also activates a local action or Close. Both controls use the system blue focus ring.
- Close has the accessible name “Close banner” by default; localise `closeLabel` when needed. Its 20px icon frame has the shared Action Button's 24px target area.
- When removing a focused Banner, the host page should move focus to an appropriate nearby control. Essential information should remain available elsewhere after dismissal.
- Colours follow Figma in both themes. Status is also available as text, so the message's meaning does not depend on icon colour alone.
