Select lets people choose from a known list without typing: a country, a currency, a person, a payment method.
It is the field version of the [Dropdown Menu](?path=/docs/components-dropdown-menu--docs): the same rows, with a label,
a hint and the states of Input, so a form reads as one system.

```tsx
<Select label="Country of residence" type="country" options={countries} onChange={setCountry} />
```

## Design decisions

What the code adds to the Figma file, and why:

- **Choice order, not list order.** In a multi-select the field keeps the order in which people picked options, as the
  Figma examples ask. When the list overflows, what they picked first stays visible. (PrimeReact would follow the list order.)
- **Search from 11 options.** The Figma guidelines show 9 rows without scrolling and a search row once the list is longer
  than 10. The code applies it by itself; `searchable` overrides it.
- **One row for every list.** Select, Compact Select, Inline Select and Dropdown Menu share the Figma *Dropdown menu item*,
  so a fix or a new option type reaches all of them.
- **Focus you can see.** Figma draws focus in `primary-soft-200`, which keyboard users can barely see; the code uses the
  system blue ring, and only for keyboard focus.
- **States are behaviour, not props.** Hover, focus and open come from the pointer and the keyboard, so they are tried
  in the examples rather than drawn one by one. Error and disabled are props, and each has its own example.

## Sizes

<Canvas of={SelectStories.Sizes} />

Only the paddings and corners change; the text stays the same size. The floating label **takes no vertical space**: leave 22px above every field in a form layout.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves focus to the field; the blue ring shows |
| ↓ or Enter or Space | Opens the list |
| ↑ ↓ | Moves through the options |
| Enter | Chooses the option (in a multi-select, ticks it and keeps the list open) |
| Escape | Closes the list and keeps focus on the field |
| Typing | Filters the list when there is a search row |

- The field is a combobox named by its label; the option under the arrow keys is announced.
- The hint and the error are read with the field; an error also marks it as invalid.
- Pictures are decorative: the option names say what is chosen.
