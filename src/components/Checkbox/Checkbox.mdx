# Checkbox

A box to turn an option on or off, on its own or with a label. With a label (`CheckboxLabel`, Figma *Checkbox label*)
it can carry a sublabel, a description and a link, and flip to the right for lists.

## Anatomy

<Canvas of={CheckboxStories.Anatomy} />

1. **Checkbox:** the box. Empty, checked or indeterminate.
2. **Label (optional):** what the option is, Body-md/Medium 14/20. The whole label is clickable.

## Sizes

<Canvas of={CheckboxStories.Sizes} />

From the left: **md-20** (20 × 20) and **sm-16** (16 × 16, the default). The label stays Body-md/Medium 14/20 in both;
the checkbox sits in a frame as tall as the first line, so it lines up with the label.

## Selection

<Canvas of={CheckboxStories.Selection} />

From the left:

- **Empty:** a grey ring.
- **Checked:** filled, with the check cut out.
- **Indeterminate:** filled, with a dash: some, not all, of the items below are selected. Use it for a parent checkbox.

## With label

<Canvas of={CheckboxStories.WithLabel} />

From the top: label only; with a **sublabel** (*(Optional)*, Body-sm); with a **description** and a **link** (Link, xs, blue);
and **flipped**, with the checkbox on the right, for lists where the text comes first. The gaps follow Figma: 8px between
the checkbox and the text, 4px between the label and the sublabel, 2px to the description, 10px to the link.

## List with a parent

<Canvas of={CheckboxStories.ListWithParent} />

A parent checkbox selects or clears all items. While only some are selected it shows the indeterminate dash.
Try it: select and clear the items.

## States

Each state shows empty, checked and indeterminate.

### Default
At rest.

<Canvas of={CheckboxStories.Default} />

### Hovered
Pointer over it: the ring gets darker; a filled box gets a little lighter.

<Canvas of={CheckboxStories.Hovered} />

### Pressed
While it is pressed: the ring turns black; a filled box gets lighter still. In Figma this state is called Active.

<Canvas of={CheckboxStories.Pressed} />

### Focused
Reached with the keyboard: the system focus ring, a 2px gap and a 4px blue ring.

<Canvas of={CheckboxStories.Focused} />

### Disabled
Not available right now: a light ring or fill, and grey text with a label.

<Canvas of={CheckboxStories.Disabled} />

### Destructive
Red in every state, for a choice that removes something. For a missing required choice, use Error.

<Canvas of={CheckboxStories.Destructive} />

### Error
A required choice that is missing, such as accepting the Terms or confirming the risks before a withdrawal: the
checkbox turns red and a message under the label says what to do. It is the same Hint text as under Input and Select,
2px under the text. Screen readers read the message with the checkbox and hear that it is invalid.

<Canvas of={CheckboxStories.ErrorState} />

Show it after people try to send the form, not while they are still filling it in. Lists and tables don't need it:
there is no wrong choice there. Figma has no error message under a checkbox; Destructive there covers both meanings,
so the code splits them: `destructive` for the look of a removing choice, `error` (with a label) or `invalid` for a mistake.

## Accessibility

- It is a native checkbox: screen readers call it a checkbox, Space switches it, it works in forms.
- With a label, the label names it and clicking the label switches it; the description is read with it. A checkbox on its own needs `aria-label`.
- Indeterminate is announced as *mixed*. PrimeReact 10 has no indeterminate state, so the component sets it on the native checkbox.
- Focus uses the system blue ring. Figma draws a 4px `primary-soft-200` frame, which keyboard users can barely see.
- An error is not shown by colour alone: `error` writes the message under the label and connects it with `aria-describedby`; `invalid` sets `aria-invalid`.
- Colours follow Figma. The empty ring (`stroke-base-300`) reaches about 1.5:1 against the surface, under the 3:1 WCAG asks for controls; the label next to it helps people find it.
