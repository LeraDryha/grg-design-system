A one-line text field with a label, an optional hint and extra information on the right.
Seven types cover the data the products ask for: plain text, phone numbers, websites, card numbers, amounts, dates and values with an action.

## Examples

Every example is a live story. Its steps also run as a test in the **Interactions** tab, so a broken behaviour shows up at once.

### Sign in

<Canvas of={InputStories.SignIn} />

The password field is the Button type with a reveal action. *Show password* turns into *Hide password* and is announced as pressed.

### Check an email

<Canvas of={InputStories.CheckAnEmail} />

The error appears after people try to send the form, not while they are still typing. It replaces the hint, turns the border red, and screen readers read it with the field.

### Format as you type

<Canvas of={InputStories.FormatAsYouType} />

Card numbers fall into groups of four, an amount takes digits and one decimal point, a date takes the locale's order and separator (DD/MM/YYYY in the UK, MM/DD/YYYY in the US, DD.MM.YYYY in Ukraine; try the Locale switch in the toolbar). On phones these fields open the number keyboard.

### Phone number

<Canvas of={InputStories.PhoneNumber} />

The country code is its own select ([Inline Select](?path=/docs/components-inline-select--docs)) with flags from [Country icons](?path=/docs/foundations-icons-country-icons--docs). The number takes digits and spaces only.

### Copy a referral link

<Canvas of={InputStories.CopyAReferralLink} />

A read-only value with a copy button. Copying is announced as *Copied*.

### Unavailable

<Canvas of={InputStories.Unavailable} />

`disabled` when the whole field is unavailable, with a hint that says why. `readOnly` keeps the value available for focus, selection and copying (see the example above).

### Controlled by a form

<Canvas of={InputStories.ControlledByAForm} />

The field supports standard React `value` + `onChange`, as well as the simpler `onValueChange`. Typing and the clear button both update the form.

## Design decisions

What the code adds to the Figma file, and why:

- **The floating label is a real label.** Inside the empty field it works as the placeholder, then floats above on focus or with a value. It stays the field's name for screen readers the whole time. It **takes no vertical space**: leave 22px above every field in a form layout.
- **Focus ring for the keyboard only.** Tab shows the blue ring; a click or tap shows the dark Active border without the ring.
- **Formatting in the field.** Card, amount, date and phone values are cleaned up while typing, so the form receives what it expects.
- **States are behaviour, not props.** Hovered and Active follow the pointer and focus; try them in any example. Error and disabled are props, and each has its own example.
- **One frame for every field.** Label, hint and Key: value are shared with Select and Text Area: see [Form Field](?path=/docs/components-form-field--docs).

## Types

All types share the same frame, sizes and states; they differ in what sits around the text.

<Canvas of={InputStories.Types} />

- **Common:** standard text or numbers. Name, title, city, address, username.
- **Phone:** a country code select, then the number.
- **Website:** a URL or domain after a protocol prefix (http / https).
- **Card:** a card number in groups of four, with the payment method.
- **Amount:** a number with a currency select. Coins come from [Coin icons](?path=/docs/foundations-icons-coin-icons--docs).
- **Date:** a date in the locale's format; with a calendar, use [Date Picker](?path=/docs/components-date-picker--docs).
- **Button:** a value with an action button: copy a referral link, reveal a password.

<Canvas of={InputStories.CardPaymentMethods} />

The Card field shows the card's payment method from [Payment method icons](?path=/docs/foundations-icons-payment-method-icons--docs). Screen readers hear its name.

## Sizes

<Canvas of={InputStories.Sizes} />

lg-44 for forms with few fields (sign-up, payment), md-40 by default, sm-32 on dense screens (filters, tables, toolbars).
Text (Body-md 14/20) and icons (20px) stay the same in every size; only paddings and corners change.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves focus into the field, then to each button in it; the blue ring shows |
| Escape | Closes the info help without moving focus |
| ↑ ↓ (country, coin) | Move through the options of the select |

- The hint and the error are connected with `aria-describedby`; an error also sets `aria-invalid`.
- Every button in the field has a name: *Clear*, *Copy referral link*, *Show password* (with `aria-pressed`).
- The country and coin selects are comboboxes with a name; the highlighted option is announced.
- Colours follow Figma. In the dark theme the prefix and unit text (`icon-base-500`) reach about 3.8:1 on the surface, below the 4.5:1 for text.
