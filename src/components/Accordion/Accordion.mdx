# Accordion

<ComponentHeader figma="151-13214" guidelines="420-7068" designTab builtOn="PrimeReact Accordion + AccordionTab" />

An expandable section that keeps its title visible and reveals a text description or key–value details when opened.

<Canvas of={AccordionStories.Playground} />
<Controls of={AccordionStories.Playground} include={['title', 'expanded', 'chevronPosition', 'icon', 'descriptionType', 'description', 'rows', 'disabled']} />

```tsx
<Accordion title="Can I cancel a transfer?" description="You can cancel a transfer while it is Pending." />
```

## Design decisions

What the code adds to the Figma file, and why:

- **A heading with a button inside.** The header is a button inside a heading; set `headingLevel` to match the page, so the section appears in the page outline.
- **Expanded is not Active.** Figma's *Active* is the pressed look; it lasts only while the pointer is down. Whether the section is open is a separate state (`expanded`).
- **Focus you can see.** Keyboard focus adds the system blue ring around the container; Figma has no Focused variant.
- **Rows without a limit.** Figma provides Rows 01–05; in code the count comes from the data.
- **Corners from the component set:** 10px closed, 12px open.

## Chevron and description

<Canvas of={AccordionStories.ChevronPosition} />

The chevron sits **after** the title by default, with an optional 20px Base icon before it (*help* by default). **Before** the title (Figma *Flip icon* On) it takes the icon's place.

<Canvas of={AccordionStories.DescriptionTypes} />

**Text** for an explanation; **Key–Value** for facts such as a reference, currency or amount. A soft 1px divider separates the description from the header.

<Canvas of={AccordionStories.KeyValueRows} />

Figma ships the description's two parts as separate components: *Description* (`AccordionDescription`) and *Key-value* (`AccordionKeyValue`).

There is one size: 14/20 text, 20px icons, 12px padding and an 8px gap in the header; 44px high when closed at 360px wide.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves to the next header; the blue ring shows |
| Enter or Space | Opens or closes the section |

- `aria-expanded` says whether it is open; `aria-controls` points to a region named by the header. Collapsed content is hidden from screen readers and the keyboard.
- Icons are decorative; the title is the control's name.
