## Design decisions

- **Any value from 0 to 100.** Figma has steps of 10% because of its variants.
- **The value can be text**, such as *8 of 10 steps*; screen readers hear it instead of the percentage.
- **Unknown length** is not in Figma; PrimeReact's moving bar, in the fill colour (see [Contributing/Tokens](?path=/docs/contributing-tokens--docs)).
- **The fill grows smoothly** (0.3s); with reduced motion it changes at once.
- **The colour is the product's call**: nothing changes on its own at 100%.
- File Upload's cards use this bar.

## Colors

<Canvas of={ProgressBarStories.Colors} />

- **Primary** for most progress; **Success** when it's good to be full; **Warning** and **Error** near or over a limit; **Blue** for information.
- The Warning fill is light against the track (Figma contrast); the value next to it says the same in text.

## Value position

<Canvas of={ProgressBarStories.ValuePosition} />

On the right for a single line, on top with a label, at the bottom with a hint; or no value.

## Accessibility

- A `progressbar` with `aria-valuenow` (0–100) or `aria-valuetext`, named by the label (or `aria-label`), described by the hint.
- Without a value it has no `aria-valuenow`, which screen readers read as busy.
- The value text is hidden from screen readers, so it isn't read twice.
