## Examples

Every example is a live story; its steps also run as a test in the **Interactions** tab.

### Single level

<Canvas of={SidebarStories.SingleLevel} />

A flat list. The current page has `aria-current="page"`; choosing a page moves it.

### With group titles

<Canvas of={SidebarStories.WithGroupTitles} />

Titles such as MAIN and OTHER group the pages; screen readers hear each list by its title.

### Multi-level

<Canvas of={SidebarStories.MultiLevel} />

A row with an arrow is a button that opens and closes its pages; it doesn't go anywhere itself. Several groups can be open. The group of the current page opens on its own, and while it is closed its row shows that the current page is inside.

### Without icons

<Canvas of={SidebarStories.WithoutIcons} />

Icons are optional on first-level rows. A collapsed sidebar needs them: without one, the first letter stands in.

### Company and account

<Canvas of={SidebarStories.CompanyAndAccount} />

The company card opens the list of companies under it; the account card opens the account menu beside it, upwards. The feature card sits above the account.

### Collapsed

<Canvas of={SidebarStories.Collapsed} />

Icons only. Hovering or focusing an icon shows its name in a tooltip; screen readers hear the name from the link itself. A group opens its pages in a menu beside it, and a badge becomes a dot (*Mass payouts, New*). The feature card is hidden.

### API reference

<Canvas of={SidebarStories.ApiReference} />

The Left badge is an [Api Icon](?path=/docs/foundations-icons-api-icons--docs): the method is part of the link's name (*POST Create an invoice*).

### On tablets and phones

Under 1024px the sidebar hides, as the Figma Tablet and Mobile top bars show: the menu button of [Topbar Navigation](?path=/docs/components-topbar-navigation--docs) opens the same pages, with the company, the theme, the language and the account, under the bar.

## Design decisions

What the code adds to the Figma file, and why:

- **Built from plain links.** Pages are links and groups are buttons that open them, so screen readers announce site navigation and links open in a new tab as usual. PrimeReact PanelMenu would read as a tree. PrimeReact still gives the menus (TieredMenu) and the tooltips.
- **Width follows the screen** (`layout="auto"`): the full 272px sidebar from 1280px, icons only (80px) from 1024px, hidden below, where the top bar's menu takes over. `layout` sets one of them.
- **Collapsed is 80px**, not Figma's 76px: the 40px rows with 20px on each side and the 56px cards need it (see [Contributing/Tokens](?path=/docs/contributing-tokens--docs)).
- **The current page inside a closed group.** The group's row takes the Active look, so people still see where they are, the common practice in admin apps; open, only the page itself is Active.
- **Collapsed extras.** Names in tooltips, groups in a menu beside the icon, badges as a dot: none of them are drawn in Figma.
- **Long names** end with an ellipsis on one line.
- **Focus** uses the system blue ring, not Figma's light grey (see Contributing/Tokens).

## Rows

<Canvas of={SidebarStories.Items} />

- **Default** and **Active** (the current page: dark semibold text on a grey tile). Hover is the same grey tile.
- **With icon**: first-level rows only. **With arrow**: a group. **Second level**: its pages, indented to the parent's text.
- **Right badge**: a short label or count ([Badge](?path=/docs/components-badge--docs), Light, sm). **Left badge**: the API method.
- **Collapsed**: a 40px square; a badge becomes a dot.

## Widths

<Canvas of={SidebarStories.Widths} />

Expand 272px and Collapsed 80px, the same pages. From top to bottom: Sidebar header (optional), Content, Feature cards (optional, expanded only), Sidebar footer (optional), 20px apart.

## Accessibility

| Key | What it does |
|---|---|
| Tab / Shift + Tab | Moves between the pages, the groups and the cards |
| Enter | Opens a page; on a group, opens or closes it |
| Space | Opens or closes a group; opens a card's menu |
| Arrow keys, Escape | Move in an open menu and close it |
| Escape | Closes a tooltip or a menu |

- The pages are a `nav` named *Main* (`aria-label`), with a list per group named by its title.
- The current page has `aria-current="page"`; a group button has `aria-expanded`.
- Collapsed rows keep their name (and badge) as text for screen readers; the tooltip only shows it.
