## Design decisions

- **The whole card is one button or link.** Figma draws the chevron as an Action Button; in code it is a picture, because a button can't sit inside another.
- **The chevron shows only when the card leads on.** Currency cards have none in Figma, so they never get one.
- **Unavailable** isn't in Figma: the grey of other disabled controls; say why in the description.
- **Any picture** can replace the icon (`leading`), such as a payment method logo.
- **The plus on the create tile** is drawn like the Secondary icon-only Button, for the same reason as the chevron.
- **Focus** is the system blue ring.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves between the cards that do something |
| Enter / Space | Opens or chooses the card |

- A card is named by everything on it: title, badge and description (*Visa, Mastercard Fee 1.50 EUR + 1.5%*).
- A chosen tile says so (`aria-pressed`).
- The description (`text-soft-500` on `bg-weak-100`) is 4.3:1 in Figma, a little under 4.5:1.
