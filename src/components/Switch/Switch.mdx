Turns one setting on or off at once, without a Save button. `SwitchLabel` adds its label, a description and a link; `ThemeSwitch` is the switch for the dark theme.

<Canvas of={SwitchStories.Playground} />

```tsx
<SwitchLabel flip label="Weekly report" description="A summary of payments and payouts." checked={on} onChange={setOn} />
```

## Design decisions

- **A real switch.** PrimeReact InputSwitch keeps a native checkbox with the `switch` role: Space toggles it and forms receive it. PrimeReact also marks its wrapper as a checkbox, which would be a second control for screen readers; the wrapper is only a box here.
- **Switch label** has the same layout and rules as Checkbox Label, at sm-16 as in Figma.
- **Switch mode** keeps its track grey in both positions, as in Figma: the icon says which theme is on.
- **Focus** uses the system blue ring.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves to the switch |
| Space | Turns it on or off |

- Screen readers hear the label, *switch*, *on* or *off*, then the description.
- A switch without a visible label needs `aria-label`.
- Known contrast from Figma: the disabled track and text are light (as in every disabled control).
