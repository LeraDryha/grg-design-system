## Design decisions

- **Any limits and step.** Figma shows 0–100% in steps of 25% as an example.
- **The handle is always black.** Figma's grey Default handle at 0 would hardly show on white (about 1.3:1) (see [Contributing/Tokens](?path=/docs/contributing-tokens--docs)).
- **The value top right** is the current value, both values for a range.
- **The tooltip** shows only while a handle is hovered, focused or dragged, so it doesn't cover the label.
- **A 24px area to press** around the 16px handle (WCAG 2.2 target size).
- **Disabled** isn't in Figma: the grey of other disabled fields.
- **Screen readers** hear the real value and its text (*2,500 USDT*); PrimeReact gives the position in percent, so the slider sets it.

## Accessibility

| Key | What it does |
|---|---|
| ← / → (↓ / ↑) | One step |
| PageUp / PageDown | Ten steps |
| Home / End | The minimum and the maximum |

- Each handle is a `slider` named by the label (and *Minimum* / *Maximum* in a range), with the value and its text.
- The sublabel describes the slider; − and + are named *Less* and *More*.
