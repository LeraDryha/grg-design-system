A link takes people to another page, view or external resource. In Figma it is called Link button.


## Design decisions

- **A real link, not a button.** PrimeReact has no link component, so this is a native `<a href>`: screen readers call it a link, Enter follows it, and the browser can open it in a new tab or copy its address.
- **Focus you can see.** Figma draws a light rounded frame (`primary-soft-200` for Black, `info-light-200` for Blue); the code uses the system blue ring, only for keyboard focus.
- **A 24px target.** The smaller sizes keep a 24px tall touch area.
- **States are behaviour, not props.** The Black link's underline darkens on hover and press; the Blue link keeps its look, as in Figma.

## Colours and sizes

<Canvas of={LinkStories.Colors} />

**Black** is the default, with an underline that gets darker on hover and press. **Blue** is for links that need to stand out from the content around them.

<Canvas of={LinkStories.Sizes} />

md-24 with a Body-lg/Semibold label, sm-20 with Body-md/Semibold, xs-16 with Body-sm/Semibold. The icon follows the size (24, 20 or 16px).

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves focus to the link; the blue ring shows |
| Enter | Follows the link |

- The label says where the link goes. Avoid *Click here* or *Read more* without context.
- The Blue link has no hover or pressed change in Figma; people still see the pointer cursor.
