## Anatomy

<Canvas of={LinkStories.Anatomy} />

1. **Container:** the link area. The Black link has a 1px line under the whole container.
2. **Icon (optional):** before or after the label. Use the standard Base icons; their size follows the link size (16, 20 or 24px). Use *maximize* for links that open an external resource. Social, country or coin icons need to be agreed first.
3. **Button label:** where the link goes, in a few words: *View all invoices*, *API references*.

<Canvas of={LinkStories.Content} />

From the left: **text only** and **text with an icon**.

## Colours

<Canvas of={LinkStories.Colors} />

From the left:

- **Black:** the default, with an underline that gets darker on hover and press.
- **Blue:** links that need to stand out from the surrounding content, such as *View details* in a card. No underline: the colour marks it as a link.

## Sizes

<Canvas of={LinkStories.Sizes} />

From the left:

- **md-24:** Body-lg/Semibold label (16/24), 24px icon.
- **sm-20:** Body-md/Semibold label (14/20), 20px icon.
- **xs-16:** Body-sm/Semibold label (12/16), 16px icon.

The smaller sizes keep a 24px tall touch area.

## Accessibility

- It is a real link (`<a href>`): screen readers call it a link, Enter follows it, and the browser can open it in a new tab or copy its address.
- With `external`, it opens in a new tab and screen readers hear *(opens in a new tab)* after the label.
- The label says where the link goes. Avoid *Click here* or *Read more* without context.
- A disabled link has no address and is marked `aria-disabled`, since links have no disabled state of their own; it is skipped by Tab.
- Focus uses the system blue ring. Figma draws a light rounded frame (`primary-soft-200` for Black, `info-light-200` for Blue), which keyboard users can barely see.
- The Blue link has no hover or pressed change in Figma; people still see the pointer cursor.
