## Examples

### Filter transactions

## Design decisions

- **A real search field**: screen readers hear *search*, phones show a Search key, Enter searches and Escape clears.
- **× appears as soon as there is text**, in every state, as the guidelines say.
- **A name for screen readers** is always there (`aria-label`, *Search* by default): the placeholder disappears as people type.
- **One style, Outstroke.** Figma marks Gray as optional and possibly deprecated (see [Contributing/Tokens](?path=/docs/contributing-tokens--docs)).
- **Loading** is not in Figma: the xs Progress Circle in the icon slot, as many products do.
- **Suggestions** while typing (a list under the field) aren't part of this component yet.

## Sizes

<Canvas of={SearchStories.Sizes} />

lg-44 and md-40 for pages, sm-32 in toolbars and panels.

## Accessibility

| Key | What it does |
|---|---|
| Enter | Searches now |
| Escape | Clears the field |

- A `searchbox` named by `aria-label`, described by the hint; busy while `loading`.
- × is named *Clear search*; after clearing, the cursor stays in the field.
- Known contrast from Figma: the disabled field is light (as in every disabled control).
