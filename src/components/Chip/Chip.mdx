## Design decisions

- **One component, four roles.** Figma draws Assist, Filter, Input and Suggestion chips alike; the code gives each its behaviour: a button (`onClick`), a check box (`selectable`), a value with a remove button (`removable`), or a plain value.
- **A chosen chip gets a check**, as in the Figma Filter chips, so the choice doesn't rest on colour alone.
- **Remove is its own button** next to the label, never a button inside a button; Backspace and Delete on it remove the chip too.
- **Hover, pressed and focus** come from the pointer and the keyboard. Focus is the system blue ring, shown only for the keyboard.

## Styles

<Canvas of={ChipStories.Styles} />

Filled on plain backgrounds; Outlined where chips sit on a grey surface or next to fields. Chosen: Filled darkens, Outlined turns soft gold.

## Sizes

<Canvas of={ChipStories.Sizes} />

md-24 by default and in md and lg fields, sm-20 in sm fields and dense filters, xs-16 inside tables and cards.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves to each chip that does something, then to its remove button |
| Space | Chooses or clears a filter |
| Enter / Space | Runs an assist or suggestion chip |
| Enter, Space, Backspace, Delete on × | Removes the chip |

- Filters are check boxes named by their label; their group is named (*Currencies*).
- Remove buttons are named *Remove* + the label. Icons and avatars are decorative.
- A chip that only shows a value isn't a Tab stop.
- Disabled text is under 4.5:1, as in every disabled control in Figma.
