A small select for a language switcher in a header, or a choice inside another field: the country code of a phone number, the coin of an amount.
It has no frame of its own and opens the same list as Select. Figma has the component only, without a guidelines page.

<Canvas of={InlineSelectStories.Playground} />
<Controls of={InlineSelectStories.Playground} include={['type', 'aria-label', 'searchable', 'disabled']} />

```tsx
<InlineSelect aria-label="Country code" type="country" options={codes} value={code} onChange={setCode} />
```

## Design decisions

- **No frame of its own.** It lives inside another field or a header; the chevron is an Action button (sm, grey), darker on hover, darkest while open.
- **No clear button.** It always holds a value, which is changed, not emptied.
- **The same list as Select.** Rows, search and keyboard are shared with Select, Compact Select and Dropdown Menu.
- **Focus separate from open.** The blue ring marks keyboard focus whether or not the list is open; closing the list restores the resting chevron even if focus stays.

## Types

<Canvas of={InlineSelectStories.Types} />

**Country** (flag), **Coin** and **Icon**: the type only changes the 20px picture. The value is a short text, Body-md/Regular: *+359*, *USD*.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves focus to the select; the blue ring shows |
| ↓ or Enter or Space | Opens the list |
| ↑ ↓ | Move through the options |
| Enter | Chooses the option |
| Escape | Closes the list |

- It is a combobox with a name from `aria-label` (*Country code*, *Currency*); the highlighted option is announced.
- The picture is decorative; the value and the option names say what is chosen.
