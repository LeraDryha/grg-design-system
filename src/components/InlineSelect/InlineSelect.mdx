A small select for a language switcher in a header, or a choice inside another field: the country code of a phone number, the coin of an amount.
It has no frame of its own and opens the same list as Select. Figma has the component only, without a guidelines page.

## Anatomy

<Canvas of={InlineSelectStories.Anatomy} />

1. **Picture:** a flag, a coin or a Base icon, 20px.
2. **Value:** a short text, Body-md/Regular: *+359*, *USD*.
3. **Chevron:** an Action button (sm, grey); darker on hover, darkest while open.

## Types

<Canvas of={InlineSelectStories.Types} />

From the left: **Country** (flag), **Coin** and **Icon**. The type only changes the picture.

## In fields

<Canvas of={InlineSelectStories.InFields} />

Input uses it in two types: **Phone** (the country code before the number) and **Amount** (the coin after the number).

## Header language

<Canvas of={InlineSelectStories.HeaderLanguage} />

The application supplies its current language and handles the selection to update translated content, routing and persistence. This example updates the content on the canvas. Use language names; a country flag does not uniquely identify a language.

## States

### Default
At rest.

<Canvas of={InlineSelectStories.Default} />

### Hovered
Pointer over it: the chevron gets darker.

<Canvas of={InlineSelectStories.Hovered} />

### Active
Open: the darkest chevron. Closing the list restores the resting or hovered chevron, even if focus remains.

<Canvas of={InlineSelectStories.Active} />

### Keyboard focus

Tab or Shift+Tab shows the blue focus ring. Clicking or tapping activates the control without the ring; typing after a click keeps the Active appearance.

A blue ring marks keyboard focus independently of whether the list is open.

<Canvas of={InlineSelectStories.Focused} />

### Disabled
Not available right now, with its field: grey text, a faded picture and a grey chevron.

<Canvas of={InlineSelectStories.Disabled} />

## Selection

Set `value` to the application's current choice, or `defaultValue` for an initial choice managed by the component. Without a matching option, the control shows its empty state. It never substitutes the first option. An empty or removed value does not fire `onChange`; the application decides how to resolve it.

<Canvas of={InlineSelectStories.EmptySelection} />
<Canvas of={InlineSelectStories.MissingValue} />

## Accessibility

- It is a combobox with a name from `aria-label` (*Country code*, *Currency*), an expanded state and the highlighted option announced while moving with the arrow keys.
- The picture is decorative; the value and the option names in the list say what is chosen.
- Keyboard focus shows the system blue ring.
