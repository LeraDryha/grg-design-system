Four types from the strongest to the quietest, five sizes, and colours for destructive and positive actions.

## Design decisions

What the code adds to the Figma file, and why:

- **Focus you can see.** Figma draws focus as a light grey ring (`primary-soft-200`, about 1.2:1 against the page). The code uses the system blue ring, and only for keyboard focus.
- **Loading keeps the width.** The spinner takes the label's place inside the same box, so the layout doesn't jump and the button can't be pressed twice.
- **States are behaviour, not props.** Hovered, Pressed (Figma *Active*) and Focused come from the pointer and the keyboard; try them in any example. Loading and disabled are props, and each has its own example.
- **Corner radii from the component set.** xlg 12, lg and md 10, sm 8, xs 6. The guidelines text lists smaller ones; the component set wins (see Contributing/Tokens).

## Types

<Canvas of={ButtonStories.Types} />

- **Primary:** the main action on a screen or in a dialog. One per area.
- **Secondary (default):** most actions. The type to use when nothing needs extra weight.
- **Outline:** alternative or less important actions next to a Primary one.
- **Text:** the quietest: inline actions, *Cancel*, dense places such as tables and toolbars.

<Canvas of={ButtonStories.Content} />

<Canvas of={ButtonStories.Colors} />

**Destructive** for actions that delete, remove or cancel something for good; **green** for positive confirmations, such as approving a payment.

## Sizes

<Canvas of={ButtonStories.Sizes} />

xlg for hero actions on marketing pages, lg for the main actions in forms and dialogs, md by default in the product,
sm on dense screens (toolbars, filters, cards), xs inside tables and small components. An icon-only button is always square.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves focus to the button; the blue ring shows |
| Enter or Space | Runs the action |

- The label is the button's name. An icon-only button needs `aria-label`, for example *Add*.
- A loading button keeps its name and exposes `aria-busy`; PrimeReact also disables it, so it can't be pressed and Tab skips it.
- A disabled button is a native disabled button: Tab skips it and it is announced as unavailable.
- Colours follow Figma. Known low contrast: the pressed Secondary button in destructive (2.6:1) and green (about 3:1); green text on the page is at the 4.5:1 limit.
