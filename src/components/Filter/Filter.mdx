A compact filter for tables and lists. It shows what it filters (*Merchant*), opens the same list as Select, and once a value is chosen
turns gold, keeps its label, shows the value or a count, and gets a clear button.

<Canvas of={FilterStories.Playground} />
<Controls of={FilterStories.Playground} include={['label', 'type', 'size', 'searchable', 'disabled']} />

```tsx
<Filter label="Merchant" type="multiple" options={merchants} searchable value={merchants} onChange={setMerchants} />
<Filter label="Status" options={statuses} value={status} onChange={setStatus} />
<Filter label="Created date" type="date" value={period} onChange={setPeriod} />
```

## Design decisions

What the code adds to the Figma file, and why:

- **Applied at once, except dates.** As in Jira, Linear and GitHub, every choice updates the table right away and the list stays open for more. A period needs two clicks (start and end), so the date filter applies on Apply. A product that loads data from a server can wait a moment after the last tick and send one request.
- **Search depends on the data, not the count.** Lists that come from data and grow (merchants, counterparties, currencies) turn search on with `searchable`; short fixed lists (status, type) don't need it. Without the prop, search comes with more than 10 options, as in Select.
- **A clear button you can reach.** PrimeReact's own clear icon sits inside the field and can't be reached with the keyboard. Here it is the Action Button next to the filter: visually inside the same frame, a separate Tab stop in code.
- **The full value is never lost.** The tooltip shows it on hover and on keyboard focus; screen readers always hear the label and what is applied (*Merchant: 2 selected, Corefy, Crypto Proxy*).
- **The same list everywhere.** Rows, search, checkboxes and the keyboard are shared with Select, Compact Select and Dropdown Menu.
- **Focus you can see.** Figma has no focus state; the code uses the system blue ring.

## Applied and sizes

<Canvas of={FilterStories.Applied} />

**None:** the label and a chevron. **Single:** the label, a divider and the value (Body-md/Medium). **Multi:** the label and a numeric Badge. **Status:** the label and a filled status Badge.
Applied filters use the gold fill (`primary-gold-muted-50`) and stroke (`primary-gold-subtle-400`); hovered they get darker, open they get the strongest gold stroke.

<Canvas of={FilterStories.Sizes} />

lg-44 and md-40 have 12 and 10px paddings and a sm-20 Badge; sm-32 has 6 × 8px paddings, 8px corners and an xs-16 Badge. Label and value stay Body-md 14/20.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves to the filter, then to its clear button |
| ↓ or Enter or Space | Opens the list |
| ↑ ↓ | Move through the options |
| Enter or Space | Chooses an option; in Multi, ticks it and keeps the list open |
| Escape | Closes the list or the calendar |
| Tab (list open) | Moves into the search, then to Select all |
| Typing (in the search) | Filters the list |

- The filter is a combobox named by its label and what is applied; the list is a listbox, and the option under the arrow keys is announced.
- The date filter is a button that opens a dialog with the calendar.
- Colours follow Figma. The Warning status Badge (Passive) is below 4.5:1 in the light theme, as on the Badge page.
