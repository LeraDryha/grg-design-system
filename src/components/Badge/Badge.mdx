A compact, static label, count or dot that adds status or category information beside other content.

<Canvas of={BadgeStories.Playground} />
<Controls of={BadgeStories.Playground} include={['type', 'variant', 'size', 'color', 'label', 'value', 'leftIcon', 'rightIcon', 'aria-label']} />

**Label** and the two icons apply to Text. **Value** applies to Numeric. Give a standalone Dot a meaningful label or `aria-label`.

```tsx
<Badge variant="light" color="success" label="Paid" leftIcon={null} rightIcon={null} />
```

## When to use

## Design decisions

- **Static, always.** Badge has no Tab stop, hover or click; Figma defines no interactive states. For actions or filters, use Button or a selection control.
- **Colour is never the only cue.** Text badges carry a word; a Dot or a count gets a name or sits next to text.
- **Sizes from the component set.** The guidelines list different Text corners and a different xs text style; the component set wins (see [Contributing/Tokens](/?path=/docs/contributing-tokens--docs)).

## Accessibility

- Badge is a static span. Its text or count is read in document order; icons are hidden from screen readers.
- A standalone Dot, or a count with an `aria-label`, is one named image.
- Updates are not announced automatically; if they need to be, add a live status message around it.
- Colours match Figma. **Warning text in the light theme falls below 4.5:1**: about 3.15:1 for Filled, Stroke and Text, and 3.04:1 for Light. Use a passing colour for essential text until the Figma tokens are revised. All text combinations pass in the dark theme.
