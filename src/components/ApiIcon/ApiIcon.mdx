## Design decisions

- **One colour per kind of change**: Post Info, Get Success, Delete Error, Patch and Put Warning, as in Figma.
- **Active** is the deeper tint for the selected endpoint, such as the current page in a sidebar.
- **No PrimeReact base**: a picture, not a control.

## Accessibility

- With text, screen readers read the method; without it, the tile is an image named by the method (*PATCH*). `decorative` hides it when the method is written next to it.
- Known contrast from Figma: the Patch and Put text is about 3:1, and every Active text 2.8–4.2:1, under the 4.5:1 for small text. The tests list it as a known issue.
