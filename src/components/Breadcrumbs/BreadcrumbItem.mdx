## Examples

Every example is a live story. Its steps also run as a test in the **Interactions** tab.

### Icon-only root

<Canvas of={Stories.IconOnlyRoot} />

Turning Text off keeps the label as the link's name. If both Icon and Text are off, the code keeps the text, so the control is never unnamed.

### Current page

<Canvas of={Stories.CurrentPage} />

Medium text and `aria-current="page"`. The current item doesn't navigate.

### A long title

<Canvas of={Stories.ALongTitle} />

The full title shows in a tooltip on hover, focus or one tap; Escape dismisses it.

## Types

<Canvas of={Stories.Types} />

One size: 14/20 text, a 20px icon (*home* by default), a 6px gap and a 200px maximum width. Hover and focus turn the text and icon strong; keyboard focus adds the system blue ring.
The group supplies separators and the overflow menu: see [Breadcrumbs](/?path=/docs/components-breadcrumbs--docs).

## Accessibility

Native links use Enter; local actions use a PrimeReact Button with Enter and Space. Icons are decorative. The current page is static unless its clipped title needs focus to show the tooltip.
