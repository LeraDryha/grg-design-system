## Anatomy

<Canvas of={Stories.Anatomy} />

1. **Control:** a native ancestor link, a local navigation button, or a static current-page label.
2. **Icon:** an optional 20px Base icon, *home* by default.
3. **Label:** the complete page title, with 6px between it and the icon.

The group supplies separators and the overflow menu; see [Breadcrumbs](/?path=/docs/components-breadcrumbs--docs).

## Types

<Canvas of={Stories.Types} />

Icon, Icon + Text and Text, from the left. Turning Text off preserves the complete accessible name. If both Icon and Text are off, code keeps the text to avoid an unnamed control.

## Size

One size: 14/20 text, a 20px icon, a 6px gap and a 200px maximum item width. The group handles ancestor overflow.

## Truncated current title

<Canvas of={Stories.LongCurrent} />

The complete title is shown in a tooltip on hover, focus or one tap. Escape dismisses it. Non-current labels wrap in this standalone part; Breadcrumbs moves long intermediate ancestors into its menu.

## Accessibility

Native links use Enter. Local actions use PrimeReact Button with Enter and Space. Icons are decorative, and icon-only controls keep their label as an accessible name. The current page is static unless its clipped title needs focus to reveal the tooltip. All focus uses the system blue ring. Default grey text is close to the AA threshold on the base surface; preserve a suitable background.
