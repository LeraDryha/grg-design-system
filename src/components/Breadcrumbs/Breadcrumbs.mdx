# Breadcrumbs

<ComponentHeader figma="574-1037" guidelines="638-1495" designTab builtOn="PrimeReact BreadCrumb + Menu + Tooltip" related={[

A navigable path from the root to the current page, with hidden ancestor levels in an overflow menu.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} include={['items', 'maxVisibleItems', 'collapse', 'aria-label', 'overflowLabel']} />

```tsx
<Breadcrumbs items={[{ id: 'home', label: 'Home', icon: 'home', showLabel: false, href: '/' }, { id: 'account', label: 'Account', href: '/account' }, { id: 'security', label: 'Security' }]} />
```

The array sets the levels, from the root to the current page; the last entry is always the current page.

## Examples

Every example is a live story. Its steps also run as a test in the **Interactions** tab.

### A deep page

<Canvas of={Stories.ADeepPage} />

With the default limit of four, a five-level path shows **root → … → parent → current**. The levels in between move into the **…** menu, in their order.
Click **…**, or Tab to it and press Enter, Space or ↓; arrows, Home and End move through the menu, Escape closes it and returns focus to **…**.
Here the ancestors have no `href`, so `onNavigate` handles the choice (client-side navigation).

### Where am I

<Canvas of={Stories.WhereAmI} />

A named navigation region with an ordered list. The root can be icon-only (its label stays its name). The current page has `aria-current="page"` and is never a link.

### A long title

<Canvas of={Stories.ALongTitle} />

Only the current title is shortened. When it is clipped, hover, keyboard focus or one tap shows it in full. Ancestors are never shortened: a long one moves into the menu instead.

### Narrow

<Canvas of={Stories.Narrow} />

The component measures the space and folds more levels into the menu when needed. The root and the current page stay visible.

## Design decisions

What the code adds to the Figma file, and why:

- **Overflow by width, not only by count.** Besides the four-entry limit from the guidelines, levels fold when an ancestor is longer than 200px or the row doesn't fit. `maxVisibleItems` changes the limit (at least 3).
- **Full names, always.** Ancestors are never cut with an ellipsis; menu labels wrap; the current title has a tooltip.
- **Real links.** With `href`, ancestors are native links (open in a new tab, copy the address). Without it, they are buttons that call `onNavigate`.
- **A 24px target.** The 20px items keep a 24px target area without changing the Figma layout.
- **Focus you can see.** The Figma focus ring is grey; the code uses the system blue ring.

## Quantity

<Canvas of={Stories.Quantities} />

The four Figma group variants, with automatic collapsing turned off (`collapse={false}`). One size: 14/20 text, 20px icons and separators, 6px gaps; items are at most 200px wide.
Each level is a Breadcrumb item, described below.

## Breadcrumb item

<Canvas of={Stories.ItemTypes} />

One level of the path; Figma has it as its own component (*Breadcrumb item*), and the group builds it from each entry in `items`.
One size: 14/20 text, a 20px icon (*home* by default), a 6px gap and a 200px maximum width. Ancestors are grey and turn strong on hover and focus; the current page is Medium.
Turning Text off keeps the label as the item's name; if both Icon and Text are off, the code keeps the text, so an item is never unnamed.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves through the ancestors and the **…** button |
| Enter | Follows a link; opens the menu on **…** |
| ↓ · ↑ · Home · End | Move through the open menu |
| Escape | Closes the menu or the tooltip |

- Separators and icons are decorative.
- The **…** button exposes `aria-haspopup` and `aria-expanded`; localise `aria-label` and `overflowLabel`.
- Colours follow Figma. Default grey text sits close to the 4.5:1 limit on the base surface; check contrast again on another background.
