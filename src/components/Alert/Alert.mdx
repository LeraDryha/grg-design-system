A message about what happened and what to do next. One shared component for inline Alerts and floating Notifications or Toasts, with five statuses.

```tsx
<Alert status="success" title="Invoice deleted" actionLabel="Undo" onAction={undo} elevated />
```

## Design decisions

What the code adds to the Figma file, and why:

- **One component for three names.** Alert, Notification and Toast share one body; only `elevated` changes. The product decides where floating messages appear and how they queue.
- **Announced by urgency.** Errors use `role="alert"`; other statuses use `role="status"`. Set `role` yourself for a non-urgent error or an urgent warning.
- **No automatic dismissal.** A message never disappears while someone is reading it or using its action.
- **Status is not colour alone.** Each status has its own icon shape, and screen readers hear a status word first (*Error*, *Success*); change it with `statusLabel`.
- **A description means sm-20.** Figma has descriptions only in sm-20, so adding one selects that size.
- **Corner radii from the component set:** 10px without a description, 12px with one. The guidelines text lists 8px; see Contributing/Tokens.

## Types, statuses and sizes

<Canvas of={AlertStories.Types} />

An **inline Alert** has no elevation and sits next to the content it concerns. A **Notification or Toast** uses Elevation XS; the shadow follows the theme.

<Canvas of={AlertStories.Statuses} />

**Warning:** something needs attention. **Error:** something failed or needs correcting. **Success:** an action completed. **Info:** useful context or an update. **Neutral:** a general notice.
**Outstroke** uses `surface-floating`; **Filled** adds the status's muted background.

<Canvas of={AlertStories.Sizes} />

sm-20: Body-md text, 20px icon. xs-16: Body-sm text, 16px icon. Both have 12px padding and 8px between parts.
Close, the action and the status icon are independent options.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves to the action, then Close; the blue ring shows |
| Enter or Space | Runs the action or closes the message |

- The icon is decorative. Close has `closeLabel`, *Close message* by default.
- The small controls keep a 24px target around their icons or labels.
- After a floating message is dismissed with the keyboard, the product should return focus to the control that opened it.
