# Action Button

A compact icon-only control for quick, local actions: copy, edit, open a small menu. It keeps the interface quiet where a full button would be too loud.

```tsx
<ActionButton icon="copy" aria-label="Copy transaction ID" onClick={copy} />
```

## Design decisions

- **A name is required.** The button has no visible text, so `aria-label` is a required prop: the code won't build without it.
- **A 24 × 24 target at every size.** sm-20 and xs-16 keep a 24 × 24 touch area around the icon, the WCAG 2.2 minimum target size, without changing the Figma layout.
- **Focus you can see.** Figma draws a light rounded frame around the icon; the code uses the system blue ring, only for keyboard focus.
- **States are behaviour, not props.** Hovered, Pressed (Figma *Active*) and Focused come from the pointer and the keyboard; try them in the examples.

## Sizes and colours

<Canvas of={ActionButtonStories.Sizes} />

md-24 on its own, sm-20 inside fields (Input's copy and reveal buttons), xs-16 next to small text (the info button of a field label).

<Canvas of={ActionButtonStories.Colors} />

- **Black:** utility actions like copy, edit, duplicate, more. In Figma and code this colour is called Grey.
- **Blue:** informational actions where the colour reinforces the meaning: info, help, view details.
- **Red:** destructive actions: delete, remove.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves focus to the button; the blue ring shows |
| Enter or Space | Runs the action |

- Say what happens, such as *Copy referral link* or *Delete row*, not the icon's name. The icon itself is decorative.
- A disabled action button is a native disabled button: Tab skips it and it is announced as unavailable.
