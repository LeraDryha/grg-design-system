## Examples

Every example is a live story. Its steps also run as a test in the **Interactions** tab.

### Choose a time range

<Canvas of={Stories.ChooseATimeRange} />

The chosen option stays highlighted after the pointer leaves and is announced as pressed. With `allowEmpty={false}` a second click keeps it; by default, as in PrimeReact SelectButton, a second click clears it.

### Switch the view

<Canvas of={Stories.SwitchTheView} />

Icon-only options keep their `label` as a name (*List view*, *Grid view*). Tab enters the group, arrow keys move between options, Space chooses.

### An unavailable option

<Canvas of={Stories.AnUnavailableOption} />

A disabled option can't be chosen. The whole group can be disabled too.

### A single toggle

<Canvas of={Stories.ASingleToggle} />

One item on its own, for an on/off choice: pass `selected` and update it in `onClick`; it exposes `aria-pressed`. The default `type="button"` doesn't submit a surrounding form.

### Narrow

<Canvas of={Stories.Narrow} />

Keep labels short. When the row can't fit, put it in a labelled horizontal scroll region; focus brings each option into view.

## Design decisions

What the code adds to the Figma file, and why:

- **Selection that stays.** Figma shows the look of each state; the behaviour (one choice, kept after release) comes from PrimeReact SelectButton and the time-range and view examples. The selected option uses Figma's *Active* style.
- **Positions are automatic.** The group gives each item its Left, Center or Right corners; a single item is rounded on both sides.
- **One line between items.** Figma's centred strokes overlap at the joins; the code draws each join once.
- **Focus above the neighbours.** The blue focus ring is drawn over the next item, so it stays visible.
- **Styles from the component set.** The guidelines text says Medium labels, a 6px md radius and 24px icons; the component uses Semibold, 8px and 20 / 16px icons, and the code follows the component.

## Button group item

<Canvas of={Stories.ItemSides} />

The button inside the group; Figma has it as its own component (*Button group item*). The group gives each item its **Left**, **Center** or **Right** corners; **single** rounds all four.
Hover adds a weak background; pressed and selected add strong text and icons (Figma *Active*). Left and right icons are independent; icon-only items use `label` as their name.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Enters and leaves the group |
| ← → | Move focus between options |
| Space | Chooses the focused option |

- Give the group a contextual `aria-label`, such as *Time range*; PrimeReact provides `role="group"`. Options are buttons with `aria-pressed`.
- In PrimeReact 10.9.9, arrow keys can focus a disabled option, but it can't be chosen.
