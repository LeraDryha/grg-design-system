## Anatomy

<Canvas of={Stories.Anatomy} />

1. **Item container:** a button with a 1px outline. The first item's left corners are rounded.
2. **Icon:** an optional Base icon, 20px in md or 16px in sm.
3. **Label:** Semibold text, with a 6px gap to each icon.
4. **Group:** a named collection of related options. Center items have square corners; the last item's right corners are rounded. Items have zero gap and a single shared border. Figma’s centred strokes overlap at the joins; CSS draws each join once.

## Types

<Canvas of={Stories.Types} />

From the top: **Text only**, **Text + icon** and **Icon only**. Each item may have its own icons. Icon-only buttons use `label` as their accessible name.

## Sizes

<Canvas of={Stories.Sizes} />

- **md-32:** 32px height, 14/20 Semibold text, 20px icons, 6px vertical and 12px horizontal padding, 8px outer corners.
- **sm-24:** 24px height, 12/16 Semibold text, 16px icons, 4px vertical and 8px horizontal padding, 6px outer corners.
- Icon-only items use equal horizontal and vertical padding, making them 32×32 or 24×24.

The component's bound styles are the source of truth: the guidelines' prose says Medium and gives md a 6px radius, while the actual component uses **Semibold and 8px**. Code follows the component in both sizes. The anatomy prose also mentions 24px icons; the actual sizes are **20px and 16px**.

### Quantity

<Canvas of={Stories.Quantities} />

The source has **6, 5, 4, 3 and 2 items**, from the top, in both sizes. The array may contain another quantity when the content needs it. The group assigns Left, Center and Right automatically. A single item receives rounded corners on both sides; an empty array renders no buttons.

## Behaviour

Selection uses [PrimeReact 10.9.9 SelectButton](https://v10.primereact.org/selectbutton/). The Figma guide describes visual states and quantity; the selection behaviour follows SelectButton and the time-range / view examples.

### Single selection

<Canvas of={Stories.SingleSelection} />

Clicking a different option selects it and clears the previous selection. Hovering only changes the hover appearance. By default, clicking the selected option clears it, as in PrimeReact SelectButton. Only single selection is supported. Use `defaultValue` for an initial ID, or `value` and `onValueChange` to control selection.

### Optional selection

<Canvas of={Stories.OptionalSelection} />

`allowEmpty` is true by default: a second click clears the selected option. `allowEmpty={false}` prevents clearing an existing selection; supply an initial value if an option must be selected from the start.

<Canvas of={Stories.RequiredSelection} />

PrimeReact owns keyboard interaction: Tab enters the group, arrow keys move focus, and Space toggles the focused option. Tab leaves the group. This wrapper does not add Enter or Home/End handlers. In PrimeReact 10.9.9, arrow navigation can focus a disabled option, but activation cannot select it.

Use the same size throughout a group. Labels stay on one line and determine each item's width. The border between adjacent items is drawn once.

### Narrow layouts

<Canvas of={Stories.Narrow} />

Keep option labels concise. When the full row cannot fit, place it in a labelled horizontal scroll region, as shown here. This preserves button sizes and joined corners; keyboard focus brings each button into view. The component itself keeps its natural width.

## Accessibility

- Give the group a contextual `aria-label`, such as “Time range”. PrimeReact provides `role="group"`.
- Every button needs a meaningful `label`; icon-only buttons expose it as their accessible name. Icons are decorative.
- Keyboard behaviour is inherited from PrimeReact SelectButton: arrows move focus and Space changes selection. Options use button roles with `aria-pressed`.
- SelectButton exposes disabled options through `aria-disabled`. They cannot change the value; the entire group can also be disabled. PrimeReact 10.9.9 can still focus individually disabled options.
- Focus uses `var(--focus-ring)` and is layered above neighbouring buttons.
- Colours follow Figma in both themes. The subtle outline is a grouping cue; preserve sufficient contrast for the labels and icons on the chosen surface.
