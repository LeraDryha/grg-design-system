## Examples

Every example is a live story. Its steps also run as a test in the **Interactions** tab.

### A toggle

<Canvas of={Stories.AToggle} />

On its own, pass `selected` and update it in `onClick`; the item exposes `aria-pressed`. For a choice between options with arrow keys, use Button group.
The default `type="button"` doesn't submit a surrounding form.

## Types, sides and sizes

<Canvas of={Stories.Types} />

Left and right icons are independent; the standalone item has plus icons on both sides by default, as in Figma.

<Canvas of={Stories.Sides} />

**Left** rounds the left corners, **Center** has none, **Right** rounds the right corners. Button group assigns them automatically; **single** rounds all four.

<Canvas of={Stories.Sizes} />

md-32: 14/20 Semibold, 20px icons, 6 × 12px padding, 8px corners. sm-24: 12/16 Semibold, 16px icons, 4 × 8px padding, 6px corners.
Hover adds a weak background; pressed and selected add strong text and icons (Figma *Active*).

## Accessibility

Tab reaches each enabled button; Enter and Space activate it. Icon-only buttons use `label`, or `aria-label` when more context is needed. Icons are decorative. Keyboard focus uses the system blue ring.
