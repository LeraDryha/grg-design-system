# Stepper Dot

<ComponentHeader
  figma="326-6369"
  designTab
  related={[{ label: 'Modal', href: '?path=/docs/components-modal--docs', relation: 'See also' }]}
/>

Dots that show where people are in a short sequence: the current step is a long bar. It only shows the step; buttons next to it move between steps.

```tsx
<StepperDot steps={4} current={step} />
```

## Examples

### Steps of a tour

<Canvas of={StepperDotStories.StepsOfATour} />

Back and Next change the step; the bar moves and screen readers hear *Step 3 of 4*.

## Design decisions

- **Any number of steps.** Figma draws four (Active 01–04); the code takes 2 to 8, the same dot and bar.
- **Shows, doesn't navigate.** The dots are too small to tap (8px), so the buttons next to them move between steps.
- **Read as text.** Screen readers hear *Step 2 of 4* (`label`), not the dots.
- **No PrimeReact base.** PrimeReact's Stepper is a full step-by-step panel; this is a plain element.

## Steps and sizes

<Canvas of={StepperDotStories.Steps} />

sm-8 in a Modal footer, xs-4 in compact places such as cards.

## Accessibility

- The dots are hidden from screen readers; a text says the step (*Step {current} of {steps}*).
- Colour and length both mark the current step.
