## Design decisions

- **Enter or a comma** adds a value, and a pasted list splits on commas: the usual way for ID and email fields.
- **No duplicates** by default (`allowDuplicate` allows them).
- **Adding a value unfolds the field**, so the new chip and the typing line stay in view.
- **The three-row limit** is measured live: the number in *+N more* follows the field width.
- **A chip under the pointer darkens**, as in the Figma Hovered field.
- **Read only** isn't in Figma: values that can be read and expanded but not changed.
- **Focus** is the system blue ring, for the keyboard only; a click shows the Active black stroke.

## Accessibility

| Key | What it does |
|---|---|
| Enter or , | Adds the typed value |
| Backspace (empty field) | Removes the last value |
| ← / → | Moves through the values |
| Backspace on a value | Removes it and returns to typing |
| Tab | Moves to the field, then to *+N more* / *Show less* |

- The field is named by its label and described by the hint or the error.
- *+N more* / *Show less* is a button with `aria-expanded`; folded values are hidden from screen readers too, and moving into them unfolds the field.
- Disabled text is under 4.5:1, as in every disabled control in Figma.
