A select without a label or hint, for tight spots next to other controls: a currency next to an amount, a country, a coin.
It opens the same list as Select. Figma has the component only, without a guidelines page.

<Canvas of={CompactSelectStories.Playground} />
<Controls of={CompactSelectStories.Playground} include={['type', 'size', 'aria-label', 'searchable', 'invalid', 'disabled']} />

```tsx
<CompactSelect aria-label="Currency" options={currencies} value={currency} onChange={setCurrency} />
```

## Design decisions

- **No clear button.** It always holds a value, which is changed, not emptied.
- **The same list as Select.** The open list, its rows and search are shared with Select, Inline Select and Dropdown Menu.
- **No label, but always a name.** `aria-label` is a required prop: a select without visible text still has a name for screen readers.
- **Never a silent choice.** An empty or removed value stays empty instead of jumping to the first option.
- **A picture with its code** (`withText`): the Convert flow shows the coin and "ETH" together, as the Select field there; the list keeps the full names (`listLabel`).
- **States are behaviour, not props.** Hovered and Active (open) follow the pointer and the list; error and disabled are props with their own examples.

## Accessibility

| Key | What it does |
|---|---|
| Tab | Moves focus to the select; the blue ring shows |
| ↓ or Enter or Space | Opens the list |
| ↑ ↓ | Move through the options |
| Enter | Chooses the option |
| Escape | Closes the list |

- It is a combobox with a name from `aria-label`; the highlighted option is announced.
- An error sets `aria-invalid`; write the reason next to the select.
