A select without a label or hint, for tight spots next to other controls: a currency next to an amount, a country, a coin.
It opens the same list as Select. Figma has the component only, without a guidelines page.

## Anatomy

<Canvas of={CompactSelectStories.Anatomy} />

1. **Container:** the frame, filled with `surface-floating`. Its border and fill show the state.
2. **Value:** a short text (Type Default) or a picture: a Base icon, a flag or a coin, 20px.
3. **Chevron:** points down, up while the list is open.

## Types

<Canvas of={CompactSelectStories.Types} />

From the left: **Default** (short text, such as *USD*), **Icon**, **Country** and **Coin**. Pictures show without text, so the select needs `aria-label`.

## Sizes

<Canvas of={CompactSelectStories.Sizes} />

From the left: **lg-44** (12px paddings), **md-40** (10px) and **sm-32** (6px top and bottom, 8px on the sides, 8px corners). Match the controls next to it.

## Selection

Set `value` to the application's current choice, or `defaultValue` for an initial choice managed by the component. Without a matching option, the control shows its empty state. It never substitutes the first option. An empty or removed value does not fire `onChange`; the application decides how to resolve it.

## Accessibility

- It is a combobox with a name from `aria-label`, an expanded state and the highlighted option announced while moving with the arrow keys.
- Enter, Space or ↓ open the list; Escape closes it.
- Keyboard focus shows the system blue ring while the control or its search input is focused, including when the list is open.
- An error sets `aria-invalid`; write the reason next to the select.
