# Featured Icon

A Base icon on a rounded tile that sets the tone of a block: the status of a Modal, the subject of an empty state or a notice. It is a picture, not a button.

```tsx

```

## Design decisions

- **One tile, any icon.** Each status brings its icon from Figma (check, information, warning, remove); `icon` replaces it.
- **Decorative by default.** Most featured icons repeat a title; `label` makes one an image with a name.
- **Filled = Off takes the surface it sits on** (`surface-floating`) with the coloured border. In Figma Neutral Off uses `bg-base-0`, the other types `surface-floating`; the code uses `surface-floating` for all, so they match on a modal in the dark theme (see [Contributing/Tokens](?path=/docs/contributing-tokens--docs)).
- **A 32px icon** for lg-48, as in Figma: Base icons gain a 32px size.

## Types

<Canvas of={FeaturedIconStories.Types} />

- **Success, Info, Warning, Error:** the result or the risk of an action, in the status colours.
- **Neutral:** a subject without a status, in grey.
- **Primary:** a subject in the brand gold, for highlights and onboarding.

Filled on is a soft colour tile; off a tile with a coloured border, for calmer screens.

## Sizes

<Canvas of={FeaturedIconStories.Sizes} />

lg-48 in Modals, md-40 and sm-32 in cards, lists and empty states.

## Accessibility

- Decorative (`aria-hidden`) unless `label` is given; then it is an image with that name.
- Colour is never the only cue: the icon shape and the text next to it carry the status too.
