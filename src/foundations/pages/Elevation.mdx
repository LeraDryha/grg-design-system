# Elevation

Five shadow levels. The dark theme has its own recipe: deeper shadows and a thin light inner edge,
so surfaces still separate on a dark canvas. Components use the same token in both themes.

Each shadow is listed layer by layer, as in the Figma effect panel: X and Y position, blur and spread in px, the colour
and its opacity. The values come from the Figma effect styles.
