# Payment method icons

<ComponentHeader status="ready" figma="80-15178" guidelines="80-14896" />

Payment method icons represent supported payment methods and providers: cards, wallets, bank transfers and crypto.
The set has 40 logos on small cards, 34 × 24, exported from Figma under their Figma names. *Empty* is a blank card
for a method without its own logo.

Payment method icons are used in three heights: 32, 24 and 20. The width follows the card: 45, 34 and 28.
Use the size that matches the component and its text, so the interface stays consistent.

## Using payment method icons

- Show the method's name next to the icon where people choose how to pay; a row of logos alone works for *We accept*.
- Don't recolour the logos: the colours are part of the brand. They stay the same in both themes.
- Icons scale without distortion, like an icon with a locked aspect ratio in Figma.
- Icons are decorative when the name is written next to them: screen readers skip them. Use `label` for an icon that
  stands alone, such as the card brand inside a card number field.

```tsx
<PaymentIcon method="visa" size={24} />
```

The key is the Figma name in lower case, with spaces turned into hyphens: *Visa* → `visa`, *Shop Pay* → `shop-pay`.
