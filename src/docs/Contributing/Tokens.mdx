# Tokens

Tokens are generated, never written by hand. Figma is the source of truth.

1. Export the variables and styles from the Figma file into `figma/variables.json` and `figma/styles.json`.
2. Run `npm run tokens`. It writes `src/styles/tokens.css` and the data for the Foundations pages.
3. Check the Foundations pages and the components in both themes.

## Icons

Icons are generated the same way. Export the Figma "Base icons" frame into `figma/icons.json` and run `npm run icons`: it writes one SVG per icon to `src/icons/base/` and the list of names. An icon keeps its Figma name, with spaces turned into hyphens (`calendar 01` → `calendar-01`). The same command builds the social icons from `figma/social-icons.json` (Figma "Social icon" set) into `src/icons/social/`. Coin, Payment method and Country icons are too many to export one by one: export the whole set as SVG and split it with `scripts/split-figma-export.py` into `figma/coin-icons.json`, `payment-icons.json` and `country-icons.json`, then run `npm run icons`. See Foundations/Icons.

## Naming

Every CSS variable maps back to exactly one Figma variable or style.

| Figma | CSS |
|---|---|
| `gold/500` (primitive) | `--color-gold-500` |
| `Text/text-strong-1000` (semantic) | `--text-strong-1000` |
| `Spasing/100` | `--space-100` |
| `Corner/md-10` | `--radius-md-10` |
| `font/size/14` | `--font-size-14` |
| Text style `Body-md/Semibold` | `--typo-body-md-semibold` and `--typo-body-md-semibold-tracking` |
| Effect style `Elevation/Light/md` and `Elevation/Dark/md` | `--shadow-md`, its value set by the theme |

Only the gold (light) and dark themes are part of this system. White-label palettes and the Display text styles (Bounded, used for marketing headlines) are skipped.

## Decided in the Storybook

| What | Figma | Storybook |
|---|---|---|
| Keyboard focus ring | 4px light grey ring (`primary-soft-200`), about 1.2:1 against the canvas | The same ring in the system blue (`--focus-ring`, Info blue), so keyboard users can see it |
| Modal overlay | #0A0A0A at 60% with Blur/sm, drawn without a variable | `--overlay`: `neutral-1000` at 60%, with `--blur-sm`; the same in both themes |
| Inverted parts | The Black feature card is drawn in the Dark mode inside the light theme | `.grg-theme-invert` gives a part the other theme: dark in the light theme, light in the dark one. The Black feature card uses it; the Black tooltip (`bg-base-1000`) swaps on its own |
| A part that keeps the light theme | The Primary feature card has dark text on gold, which turns white (about 2:1) in the dark theme | `data-theme="light"` on the part: the generated `[data-theme='light']` block brings the light values back inside the dark theme |

## Known differences between Figma and code

Token differences and agreed implementation decisions. The table records how code handles each difference from Figma.

| Where | What | In code |
|---|---|---|
| `font/family/display` | The variable says Nunito Sans, but the Display text styles use Bounded | Display styles are not part of the Storybook |
| Text styles | Line height 22 (Title-sm) has no variable | The style token holds the raw value |
| `Spasing` | The collection name has a typo and holds a Boolean variable | Read as spacing; the Boolean is skipped |
| `text-inverce`, `icon-inverce` | Typo in the token names | Kept, so names still match Figma |
| Button guidelines | The Sizes text lists corner radii sm 8, xs 6, xs 6, xs 6, xxs 4, while the component set uses lg-12, md-10, md-10, sm-8, xs-6 | Follows the component set |
| Alert, Notification & Toast guidelines | The Sizes text lists 8px corners for both sizes; the component set uses md-10 without a description and lg-12 with one | Follows the component set; descriptions use sm-20 only |
| Badge guidelines | The Sizes text lists 4px Text corners for md/sm and 11/16 text for xs; the component set uses 6px corners for md/sm and Caption-xs/Medium 10/12 for xs. The xs description is also labelled md-24 | Follows the component set: md/sm corners 6px, xs corners 4px, text 12/16 and 10/12 |
| Button / Loading | Figma presents Loader and Disabled as separate visual states | Loading uses PrimeReact Button's native disabled behaviour: activation is blocked and Tab skips it. The loader keeps its accessible name and `aria-busy` |
| Input Otp examples | *Didn’t receive the code? Click to resend* is available straight away | The examples count down 30 seconds (*Resend in 0:30*) before the resend button appears, so people wait for the first code. To be added to Figma |
| Featured icon / Neutral, Filled = Off | The tile uses `bg-base-0`; every other type uses `surface-floating` | `surface-floating` for all, so the tile matches the Modal surface in the dark theme |
| Sidebar navigation / Collapsed | The collapsed sidebar is 76px wide, but its 40px rows with 20px sides and its 56px cards with 12px sides need 80px | 80px |
| Topbar navigation / Toolbar item, Active | The active page keeps Body-md/Medium in the bar, while the active Sidebar item is Semibold | Semibold, as in the sidebar |
| Topbar navigation / Exchange, Desktop | 130px sides at 1440px, without a variable | The content centred in 1180px (1440 − 2 × 130), at least 24px from the edges |
| Notification feed / Header and Footer | The title reads *Notification* and the footer *View all notification* | *Notifications* and *View all notifications* |
| Pagination / Navigation controls | Previous comes before First (`‹ «`) and Next before Last (`› »`) | First and Last on the outside, `« ‹ … › »`, as is usual. To be fixed in Figma |
| Feature cards / Primary, Support | The border uses the palette colour `gold/600`, not a variable | `primary-gold-base`, the card's own gold |
| Social Button / Disabled | No dedicated Disabled variant in Figma | Native disabled behaviour, with `text-disabled-400`, `icon-disabled-400` and `stroke-disabled` in both themes |
